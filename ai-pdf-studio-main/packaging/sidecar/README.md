# Python sidecar

The sidecar speaks newline-delimited JSON-RPC 2.0 over stdin/stdout. Every
request includes an `auth` field containing the per-process token generated by
Flutter. Responses and notifications are JSON only; diagnostics go to stderr.

Implemented methods include:

- `system.handshake`, `system.health`, `system.shutdown`
- `job.cancel`, `job.result`
- `library.list`, `library.upsert`
- `pdf.inspect`, `pdf.extractText`
- `chat.ask`

Long-running chat operations return a `jobId`, emit `job.progress` and
`job.finished`, and can be cancelled with `job.cancel`. Error responses use
JSON-RPC error codes and a structured `data.kind`.

Build on Windows with:

```powershell
.\tools\build_sidecar.ps1
```
